# MAM2ADMM-Series00-Git-alaoui-assia
This repository is part of the MAM2ADMM course and is used to learn-by-doing the basics of Git and GitHub: creating repositories, working with branches, committing changes, and pushing them to a remote repository. The goal is to acquire the essential skills for managing a reproducible data analysis pipeline and collaborating effectively.
# Introduction
This repository is created to learn-by-doing the basics of Git and GitHub.  
Until now, my experience with version control has been almost non-existent, but I am eager to improve.  
I look forward to learning how these tools can help me organize projects, collaborate more effectively, and ensure the reproducibility of my work.
